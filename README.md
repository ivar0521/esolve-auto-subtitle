# 自動字幕ツール（DaVinci Resolve 無料版向け・Mac）

動画の中で話している声を自動で文字にして、DaVinci Resolve で読み込める字幕ファイル（`.srt`）を作ります。

- 音声認識には Whisper（無料）を使います。**処理はすべて自分の Mac の中で行い、動画をネットに送りません。**
- 日本語向けに、字幕を読みやすい長さ（1枚あたり最大24文字、単語の途中では切らない）で自動的に区切ります。
- DaVinci Resolve の無料版で使えます。

---

## 1. 最初に1回だけやる準備

1. このページ上部の緑のボタン **「Code」→「Download ZIP」** を押してダウンロードします。
2. ダウンロードした ZIP をダブルクリックして展開し、できたフォルダを「書類」など好きな場所に移動します。
3. フォルダの中の **`setup.command`** をダブルクリックします。
   - 「Apple は…マルウェアが含まれていないことを検証できませんでした」と出たら「完了」で閉じ、
     **システム設定 →「プライバシーとセキュリティ」** の一番下にある **「このまま開く」** を押してから、もう一度ダブルクリックします（ファイルごとに初回だけ必要です）。
   - まとめて許可したい場合は、ターミナルで `xattr -dr com.apple.quarantine ` と入力し、このフォルダをドラッグ&ドロップして Enter を押します。
   - 「Python が見つかりません」と出たら、https://www.python.org/downloads/ から Python をインストールしてから、もう一度実行します。
4. 「✅ 準備完了！」と表示されれば準備は終わりです。

## 2. 字幕を作る

1. **`字幕を作る.command`** をダブルクリックします（初回は上と同じ許可が必要です）。
2. 字幕を付けたい動画ファイルを、黒い画面（ターミナル）に **ドラッグ&ドロップ** して Enter を押します。
3. 精度を選びます。
   - `1`（既定）：高精度。時間がかかります。
   - `2`：速い。精度は少し下がります。
   - 次の質問は、普段はそのまま Enter で大丈夫です。声が抜けてしまうときだけ `3` を選ぶと、全部の音を文字起こしします（BGM だけの所に変な字幕が出ることがあります）。
4. 終わると、**動画と同じ場所に、同じ名前の `.srt` ファイル**ができます。
   - 例：`インタビュー.mp4` → `インタビュー.srt`

> 初回だけ、音声認識モデルのダウンロードに数分かかります（高精度モデルは約1.6GB）。

## 3. DaVinci Resolve に読み込む

1. Resolve のメニューから **「ファイル」→「読み込み」→「字幕…」** を選び、作った `.srt` を選びます。
2. メディアプールに字幕が入るので、タイムラインにドラッグします。自動で字幕トラックができます。
3. 字幕の開始位置を、**元の動画クリップの開始位置にそろえます。**
   - 字幕のタイミングは「元の動画の最初」を基準にしているためです。
4. 見た目は下の「字幕の見た目を変える」で一括変更できます。

### 字幕の見た目を変える（位置・縁取り・影）
字幕ファイル（.srt）には見た目の情報を入れられないので、Resolve 側で設定します。字幕トラック全体にまとめて効きます。

1. タイムライン上の字幕を1つクリックし、右上の **「インスペクタ」** を開きます。
2. **「キャプション」** タブで **「トラックスタイルを使用」** にチェックが入っていることを確認します。
3. **「トラック」** タブを開いて、次のように設定します。
   - **位置 → Y**：数字を小さくすると字幕が下に下がります。
   - **ストローク（縁取り）**：色を黒、サイズを 2〜4 くらいにします。文字のまわりに黒いふちが付きます。
   - **ドロップシャドウ（影）**：色を黒、不透明度を 60〜80% くらいにします。
   - さらに見やすくしたいときは **背景** をオンにして、黒・不透明度 40% くらいにすると帯が付きます。

### うまくいかないとき
- **字幕の内容を少し直したい** → Resolve 上で字幕をダブルクリックすれば直接編集できます。
- **カット編集した後の動画に字幕を付けたい** → Resolve で書き出した完成動画（または音声だけ書き出したファイル）をこのツールに入れて、タイムラインの先頭にそろえてください。

## 詳しい設定（ターミナルで使う場合）

```bash
./.venv/bin/python auto_subtitle.py 動画.mp4 --model small --max-chars 20
```

| オプション | 内容 | 既定 |
|---|---|---|
| `--model` | `small`（速い）/ `medium` / `large-v3-turbo`（高精度） | `large-v3-turbo` |
| `--language` | 話している言語。`auto` で自動判定 | `ja` |
| `--max-chars` | 1枚の字幕の最大文字数 | `24` |
| `--keep-punctuation` | 字幕の末尾の「。」を残す | 残さない |
| `--no-vad` | 無音の自動スキップを止め、全部の音を文字起こしする | スキップする |

テスト：`python3 -m unittest discover -s tests -t .`
